# Back-office Creniaut — Tableau Kanban — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `https://todo.notias.fr`, a Kanban board shared by the two Creniaut members (4 fixed columns, project filter, ticket drawer with history and images), that Claude can read and move through the Supabase MCP.

**Architecture:** Vite + React SPA talking directly to a dedicated Supabase project (Auth Google, Postgres with RLS, private Storage bucket). History and `last_actor` are written by Postgres triggers, so Claude's SQL and the app's writes are traced the same way. Static build served by nginx, built by Coolify from the repo.

**Tech Stack:** Node 24, npm, Vite 7, React 19, TypeScript 5.9 strict, Chakra UI v3, TanStack Query 5, supabase-js 2, React Router 7, dnd-kit, Vitest 4 + Testing Library, ESLint 9, Prettier.

**Spec:** `docs/superpowers/specs/2026-11-13-tableau-design.md` (French). Visual reference: `docs/maquette-tableau.html`.

## Review Focus

1. Unknown project slug in the URL (`/todo/foo`, renamed project): show « Projet inconnu » with a link « Voir tous les projets », not an empty board. Test in Task 5.
2. `?ticket=<id>` pointing to a deleted or unknown ticket (old shared link): drawer stays closed, the param is removed, toast « Ticket introuvable ». Test in Task 6.
3. A move or edit that fails (network, RLS, expired session): the card goes back to where it was and a toast says « Modification non enregistrée ». Test in Task 3.
4. Pasting into the drawer: image files upload; plain text still pastes normally into the description; HEIC or 8 MB photos are refused with the French message and nothing is sent. Tests in Tasks 2 and 6.
5. A Google account outside `members`: sees « Accès réservé » with its e-mail and « Se déconnecter », and receives zero rows from every table and the bucket. Tests in Tasks 4 and 9.
