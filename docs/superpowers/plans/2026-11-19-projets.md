# Créer, renommer et archiver les projets — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une fenêtre « Projets » au bout des onglets pour créer, renommer (nom, couleur), archiver et restaurer un projet ; un projet archivé disparaît du tableau et n'accepte plus de ticket.

**Architecture:** Migration Supabase (colonne `archived_at`, droits par colonne, déclencheur sur `tickets`) vérifiée par `scripts/check-db.mjs`. Fonctions pures dans `src/board/projects.ts` (slug, palette, filtres), appels Supabase dans `api.ts`, mutations TanStack dans `queries.ts`, UI Chakra v3 dans `ProjectsDialog.tsx`. Le filtrage des archivés se fait côté client.

**Tech Stack:** Vite, React 19, TypeScript strict, Chakra UI v3, TanStack Query, React Router, Vitest + Testing Library, Supabase (Postgres RLS).

**Spec:** `docs/superpowers/specs/2026-11-19-projets-design.md`

## Global Constraints

- Code et identifiants en anglais, textes d'interface en français, **pas de commentaires dans le code**, pas de `any`.
- Toute requête Supabase passe par `src/board/api.ts` ; les composants n'importent pas le client.
- Couleurs de l'interface : tokens `app.*` de `src/theme.ts` ; seules les couleurs de projet sont des `oklch(...)` en dur (palette).
- Le slug est figé après création ; aucune suppression de projet.
- `npm run lint`, `npm run check-types`, `npm test` passent ; `npm run check:db` passe après `npx supabase db push --db-url "$DATABASE_URL"`.
- Textes exacts : bouton « Projets » (aria-label « Gérer les projets »), titre « Projets », « Nouveau projet », « Nom », « Couleur », « Adresse : /todo/<slug> », « Créer », « Modifier », « Enregistrer », « Annuler », « Archiver », « Restaurer », « Archivés (n) », « Ce projet existe déjà », « n tickets » / « 1 ticket » / « 0 ticket ».

## Review Focus

- Nom fait uniquement de ponctuation ou d'emoji (« !!! ») : slug vide → « Créer » grisé, aucun appel réseau.
- Nom dont le slug égale celui d'un projet **archivé** (« Notia » quand `notia` est archivé) : « Ce projet existe déjà », pas d'insertion.
- Renommer avec un nom vide ou que des espaces : « Enregistrer » grisé ; le nom est enregistré `trim()`é.
- Projet archivé alors qu'on est sur `/todo/<son slug>` : retour sur `/todo` sans écran « Projet inconnu ».
- Toutes les teintes de la palette déjà prises : la couleur par défaut reste définie (première de la palette).
